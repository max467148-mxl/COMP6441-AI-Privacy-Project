# Ethics

This project must not attempt to obtain, infer, or publish information about real people.

## Controls

- All profiles are synthetic.
- No real addresses, phone numbers, account identifiers, medical records, or financial records are used.
- The project does not test cross-user leakage from a production system.
- The report should say "inference-based privacy leakage", not "confirmed real data breach".
- Raw outputs should be checked before publication to ensure they do not include accidental real identifiers.

## AI Use Disclosure Draft

Generative AI tools were used to help design the experiment structure, create synthetic data, write code, and draft documentation. The project author reviewed the methodology, executed the experiment, preserved raw outputs, interpreted the results, and is responsible for the final analysis. No real personal data was used.
