# Project Rules

- Use synthetic data only.
- Never access files outside this repository for experiment inputs.
- Never collect information about real people.
- Never store API keys in source files.
- Never claim that a model leaked real user data.
- Clearly separate observed results, inference, and speculation.
- Do not fabricate final experiment results, screenshots, or timestamps.
- All generated code must be understandable to an undergraduate student.
- Prefer simple Python and clear comments over complex frameworks.
- Preserve raw experimental outputs for reproducibility.
